# Настройка кириллицы от 01.11.2026

В оригинале основной текст набран Avenir LT Std Light. Русские глифы были добавлены отдельным SDF-атласом; их переход сглаживания отличался от исходного, и буквы выглядели бледнее.

В текущем выпуске скорректированы только области 66 русских букв в четырёх атласах Avenir, включая вариант с тенью. Значения поля вокруг контура пересчитаны как `clamp(128 + (value - 128) * 1.75 + 10, 0, 255)`. Пустой фон остаётся нулевым. Латиница, прочие исходные знаки, размеры и интервалы сохранены. Буквы вручную не перерисовывались.

Результат пробной настройки одобрен пользователем в игре. Сравнение с пробой подтверждается точным совпадением пикселей атласов. Новый публичный пакет использует актуальные тексты от 28 октября.

## Воспроизведение для разработчиков

В `installer/build_font_density.py` находится генератор. Требуются Python 3.10+, UnityPy и Pillow. На вход подаются `payload/Night Call_Data` из пакета 2026.10.28 и папка `Night Call_Data` собственной игры для чтения типовых зависимостей. Выходная папка должна быть новой и отдельной. Генератор не устанавливает патч в игру.

```text
python installer/build_font_density.py --input-data <данные-пакета-2026.10.28> --output-data <новая-папка> --game-data <данные-собственной-игры> --report font-build.json
```

Принимаются только два исходных файла с закреплёнными SHA256. После записи проверяются точное содержимое текстур и побайтовая сохранность всех прочих объектов. Готовые игровые ресурсы распространяются только в архиве релиза, в Git их нет.
