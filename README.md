# Night Call — русский перевод

Полный русский перевод игры **Night Call** (версия 1.3.7, Steam). Основной источник смысла — французский оригинал, английский использовался для сверки. Переведено 236 сцен, 921 ключ интерфейса, ответы, досье и улики; ручная сверка по французскому проведена для всех сцен и всего интерфейса.

## Установка

1. Скачайте архив `NightCall_Russian_FR_*.zip` из раздела [Releases](../../releases/latest) и распакуйте в отдельную папку (не в папку игры).
2. Закройте игру. Запустите **Проверить.cmd**, затем **Установить.cmd**.
3. Запустите игру через Steam и в настройках выберите язык **«Русский»** (перевод занимает английский слот).

Путь по умолчанию: `D:\Games\Steam\steamapps\common\Night Call`. Другой путь: `powershell -File Install-NativePatchFR.ps1 -GamePath "полный\путь"`.

**Обновление с прежней версии:** сначала запустите **Восстановить.cmd**, затем **Установить.cmd**.

**Откат:** **Восстановить.cmd**. Оригинальные файлы сохраняются в `.NightCallRussianBackups` внутри папки игры; сохранения игрока не затрагиваются. Проверка целостности Steam вернёт оригинальные файлы — тогда установите заново.

Изменяются 8 файлов: `resources.assets`, `sharedassets0.assets`, `sharedassets3.assets`, `sharedassets5.assets`, `level1`, `level3`, `level7`, `Managed/Assembly-CSharp.dll`. Установщик сверяет SHA256 и не работает с другой сборкой игры. BepInEx и другие загрузчики не нужны; если остался старый мод с `winhttp.dll`, отключите его.

## Что улучшено

Читайте [docs/CHANGES_RU.md](docs/CHANGES_RU.md): что было, что стало и почему исправили — по персонажам, с французским оригиналом (внимание: спойлеры).

Среди прочего исправлены ошибки самого оригинала: перепутанные развязки отелей Камиля и Антуана, отсутствующая иконка в ответе Алисии, разные имена одного мальчика у Фрагонара.

## Состояние

Кандидат в релиз: автоматические проверки пройдены (83 976 проверок диалогового движка, структура ресурсов, парсер, установщик), но **полное прохождение игры вживую не выполнено**. Если встретите ошибку — откройте [Issue](../../issues) с названием сцены и скриншотом.
