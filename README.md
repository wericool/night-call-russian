# Night Call — русская локализация

**Финальная версия от 28 октября 2026 года** для Windows-версии игры Night Call в Steam.

Основной источник перевода — **французский оригинал**. Английский текст использовался как вспомогательный источник для сверки контекста.

Переведены все 236 игровых сцен, варианты ответов, интерфейс, досье и улики, газеты, радио, телефонные разговоры, 481 запись Пассидекса, титры и предупреждение при запуске. Имена, обращения и повторяющиеся термины согласованы между сценами.

## Скачать и установить

1. Скачайте **NightCall_Russian_2026-10-28.zip** из [последнего релиза](https://github.com/wericool/night-call-russian/releases/latest) и распакуйте в отдельную папку.
2. Закройте игру. Если уже установлена предыдущая нативная версия русификатора, сначала запустите **Восстановить.cmd** из нового архива.
3. Запустите **Установить.cmd**. Путь по умолчанию: `D:\Games\Steam\steamapps\common\Night Call`.
4. Запустите игру через Steam и выберите в настройках язык **«Русский»**.

Для другого расположения игры выполните команду из папки русификатора:

```bat
Установить.cmd -GamePath "полный путь к папке Night Call"
```

**Проверить.cmd** проверяет совместимость и контрольные суммы. **Восстановить.cmd** возвращает оригинальные файлы из `.NightCallRussianBackups` внутри папки игры. Сохранения игрока установщик не изменяет.

Русификатор устанавливается непосредственно в игровые файлы. Если остался старый мод с загрузчиком `winhttp.dll`, сначала отключите его.
