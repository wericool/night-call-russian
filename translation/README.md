# Исходники перевода

- `reviewed/` — по одному JSON на сцену: итоговый русский текст реплик и ответов (основа — французский оригинал).
- `passidex_reveals_ru.txt` — 481 запись Пассидекса (`номер|текст`).
- `../installer/` — установщик (`Install-NativePatchFR.ps1`, `.cmd`) и скрипт `patch_extra_text.py`, который добавляет Пассидекс, предупреждение при запуске и титры.

Файлы игры в репозиторий не входят.
