# Исходные тексты локализации

Снимок финальной версии от 28.10.2026. Основной смысловой источник — французский оригинал.

- `reviewed/` — 236 редакторских записей: текст, контекст, решения, ссылки и хеши исходников. Комментарии содержат историю решений; поздние явные уточнения заменяют прежние решения.
- `compiled_dialogues.json` — текущий экспорт 200 диалогов с действующими переходами, переменными и командами.
- `scripts/` — 36 текстовых игровых сценариев, включая звонки, газеты и сон.
- `ui_ru.json` и `ui_aliases_ru.json` — интерфейс и дополнительный псевдоним DISPLAY MODE.
- `passidex_reveals_ru.txt` — 481 запись Пассидекса.
- `credits_ru.json` — восемь уточнённых полей титров; остальные поля входят в готовый пакет.

Это исходные тексты для сверки. Для установки используйте ZIP из Releases: игровые двоичные файлы в Git не хранятся. Данные проекта являются производной от первого русификатора Artem Lytkin (4RH1T3CT0R); уведомление об авторстве и лицензия сохранены в корне репозитория.
